# Consullo TensorRT-LLM Blackwell fork

This community fork is preparing a reproducible high-throughput Qwen3.8-27B NVFP4 and DFlash2 configuration for NVIDIA Blackwell consumer GPUs.

- [Patch and release status](https://github.com/Consullo-Public/TensorRT-LLM/blob/codex/public-landing/CONSULLO_PATCHES.md)
- [Concurrency evaluation suite](https://github.com/Consullo-Public/TensorRT-LLM/tree/codex/public-landing/examples/consullo/qwen38_dflash2)
- [Installer and qualification documentation](https://github.com/Consullo-Public/qwen38-dflash2-tensorrt-llm)
- [NVIDIA upstream](https://github.com/NVIDIA/TensorRT-LLM)

No Consullo release is supported until the public-only clean-install and evaluation procedure passes on `minsky`.
